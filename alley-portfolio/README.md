# Alley Portfolio

Welcome to Alley’s personal portfolio website! This project showcases my work as a designer, highlighting my skills, projects, and contact information.

## Project Structure

The project is organized as follows:

```
alley-portfolio
├── index.html          # Main entry point of the website
├── pages               # Contains additional pages
│   ├── about.html      # About me page
│   ├── portfolio.html   # Portfolio gallery
│   ├── contact.html     # Contact form
│   └── resume.html      # Resume details
├── assets              # Contains assets for the website
│   ├── css
│   │   └── styles.css   # CSS styles for the website
│   ├── js
│   │   └── script.js     # JavaScript functionality
│   └── fonts
│       └── custom-fonts  # Custom fonts used in the website
├── projects            # Individual project details
│   ├── project-1.html   # Details of project 1
│   ├── project-2.html   # Details of project 2
│   └── project-3.html   # Details of project 3
└── README.md           # Project documentation
```

## Getting Started

To view the website, simply open the `index.html` file in your web browser. All other pages can be accessed through the navigation links provided on the homepage.

As a designer, I believe in creating visually appealing and user-friendly experiences. This portfolio reflects my design philosophy and showcases my skills in various projects.
